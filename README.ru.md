## Состояние

**Рабочая сборка, но не полностью проверенная.** Вместе с портом Valoria библиотека загружается, проходит перезагрузку ресурсов и компиляцию шейдеров и работает в живом мире (клиент и выделенный сервер). Отдельные возможности (модификаторы музыки, текстовые эффекты, постобработка, процентная броня, скины) ещё требуют целенаправленного тестирования — см. [KNOWN_ISSUES.ru.md](KNOWN_ISSUES.ru.md).

## Что изменилось

Каждая нетривиальная переработка (регистрация, события, сеть, компоненты данных, рендер, миксины) описана в [PORTING.ru.md](PORTING.ru.md), а каждое место в коде помечено комментарием `// PORT NOTE:` с объяснением. API библиотеки перенесён полностью — ничего не заглушено и не удалено.

Исправления, сделанные после первоначального порта, перечислены по коммитам в **[CHANGELOG.ru.md](CHANGELOG.ru.md)**; открытые, унаследованные и ещё не проверенные проблемы собраны в **[KNOWN_ISSUES.ru.md](KNOWN_ISSUES.ru.md)**. Пожалуйста, сверьтесь с этим списком, прежде чем открывать issue.

Что важно знать зависимым модам:

- В 1.21 зачарования описываются данными. Зачарования Tridot теперь применяются через теги предметов (`tridot:enchantable/dash_weapon`, `radius_weapon`, `overdrive`, `shield`) — пометьте свои предметы тегами.
- Capabilities стали data attachments NeoForge; `INBTSerializable` теперь получает `HolderLookup.Provider`.
- `SimpleChannel` заменён на `CustomPacketPayload` + `StreamCodec` (`PacketHandler.addRegistration` по-прежнему позволяет другим модам регистрироваться в канале Tridot).
- Идентификаторы модификаторов атрибутов — `ResourceLocation`; `Tridot.BASE_PROJECTILE_DAMAGE_ID` заменяет старый UUID.

## Разработчикам

Собрать локально и опубликовать в локальный Maven-репозиторий:

```bash
./gradlew build publishToMavenLocal
```

Затем в `build.gradle` вашего мода:

```groovy
repositories {
    mavenLocal()
}

dependencies {
    implementation "pro.komaru:Tridot:1.21.1-1.0.169"
    // или, чтобы компилироваться только против API:
    compileOnly "pro.komaru:Tridot:1.21.1-1.0.169:api"
}
```

## Что предлагает Tridot

> **Tridot** предоставляет утилиты почти для всего, что нужно разработчику;
> - упрощает вычисления и хранение данных с помощью собственных структур
> - даёт удобные методы рендера «для красоты»
> - улучшает опыт моддинга для более надёжных дополнений
> ...и не только!

### Тряска экрана — хоть землетрясение
> Использует тригонометрию, чтобы всё выглядело естественно
### Замена компонентного `Style`
> `DotStyle` добавляет класс `DotStyleEffect`, который помогает изменять отрисовку текста
- Собственные эффекты символов, есть встроенные.
### `SplashHandler` для своих сплэшей
> Добавляйте настраиваемые сплэши на главный экран
- Сплэши для отдельных языков
- Переводимые сплэши
- Вес, управляющий шансом появления
### Система скинов для `Item` и `Armor`
> Меняйте модели предметов и брони с помощью настраиваемой системы скинов
### Модификаторы музыки
> Музыка меняется в зависимости от условий
- Музыка для конкретных биомов
- Музыка для конкретных данжей (структур)
### Модификаторы названий атрибутов
### Броня с процентной защитой
> Новое свойство защиты, уменьшающее получаемый урон в процентах
- Снимает ванильный потолок 80 %, броня может давать до 100 % защиты
### Гибкие системы на билдерах
> Надёжный моддинг с новыми системами становится ещё проще
- Билдеры брони
- Билдер команд
- Билдеры частиц
- Билдеры рендера
- - кубы, лучи, вершины и т. д.
